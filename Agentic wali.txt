│  │ │                                                                │   │    │
│  │ │ B. Node Features                                              │   │    │
│  │ │    ├─ Follower count (influence score)                       │   │    │

│  │ │    ├─ Input: Network graph + node features                    │   │    │
│  │ │    ├─ Training: Historical spread patterns (Twitter15/16)     │   │    │
│  │ │    └─ Output: Probability each node will share               │   │    │
│  │ │                                                                │   │    │
│  │ │ B. Simulate Spread (Monte Carlo)                              │   │    │
│  │ │    ├─ Run 1000 simulations                                    │   │    │
│  │ │    ├─ Each iteration: nodes share based on GNN probability    │   │    │
│  │ │    ├─ Track: Cumulative reach over time                       │   │    │
│  │ │    └─ Average across simulations                              │   │    │
│  │ │                                                                │   │    │
│  │ │ C. Time-Series Forecast                                       │   │    │
│  │ │    ├─ 6 hours:    1,200 users (current trajectory)            │   │    │
│  │ │    ├─ 12 hours:   3,500 users                                 │   │    │
│  │ │    ├─ 24 hours:  12,400 users                                 │   │    │
│  │ │    ├─ 48 hours:  45,000 users                                 │   │    │
│  │ │    └─ Peak time: 18 hours from now                            │   │    │

│  │                                                                      │    │
│  │ Step 4.4: RISK ASSESSMENT                                            │    │
│  │ ┌───────────────────────────────────────────────────────────────┐   │    │
│  │ │ Calculate Viral Risk Score (0-1):                             │   │    │

│  │ │ Where:                                                         │   │    │
│  │ │ ├─ reach = predicted 24h users / 1M (normalized)              │   │    │
│  │ │ ├─ velocity = current growth rate                             │   │    │
│  │ │ ├─ influence = avg follower count of spreaders                │   │    │
│  │ │ └─ topic = sensitivity (health > politics > general)          │   │    │
│  │ │                                                                │   │    │
│  │ │ Output Example:                                                │   │    │
│  │ │ ├─ Viral Risk: 0.87 (HIGH)                                    │   │    │
│  │ │ ├─ Predicted reach: 45,000 users in 48h                       │   │    │
│  │ │ ├─ Bot involvement: 23% of shares                             │   │    │

│  │ │ └─ Recommendation: URGENT INTERVENTION NEEDED                 │   │    │
│  │ └───────────────────────────────────────────────────────────────┘   │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                                                                               │
│  OUTPUT: Viral forecast + Risk score → Pass to Strategist                    │
│                                                                               │
│  TECHNICAL STACK:                                                             │
